# 山东省考信息

山东省考是山东省各级机关考试录用公务员的简称，由山东省公务员局统一组织，报名和公告发布在“灯塔-党建在线”平台。

## 核心信息

| 项目 | 说明 |
| --- | --- |
| 公告/报名入口 | [灯塔-党建在线](https://www.dtdjzx.gov.cn/) |
| 笔试科目 | 行政职业能力测验 + 申论（部分职位加专业科目） |
| 申论分类 | A 类（省级机关）、B 类（省属基层单位） |
| 面试形式 | 以结构化面试为主，部分职位有专业能力测试 |
| 综合成绩 | 无专业测试：笔试 40% + 面试 60% |
