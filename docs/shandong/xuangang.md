# 山东省考选岗与省情

## 选岗步骤

1. **先筛资格**：专业、学历、学位、政治面貌、基层经历、户籍/生源限制。
2. **再看地点**：省直、市直、县直、乡镇，是否接受异地和基层。
3. **比较竞争**：招录人数、限制条件、往年进面分、报名人数。
4. **确认服务期**：乡镇和艰苦边远岗位常有最低服务年限要求。

山东省考职位分省级机关、省属基层单位、市及以下机关等，申论试卷也会按层级分类。选岗时同时确认职位对应的试卷类别。

## 山东岗位特点

- 省会、计划单列市和发达地市竞争通常更激烈。
- 乡镇、街道岗位数量多，但服务期和实际工作强度要提前了解。
- 公安、监狱、戒毒等岗位有体能、体检特殊要求。
- 专业限制越具体的岗位，符合人数通常越少。

## 山东省情素材

面试和申论可以结合以下山东关键词：

- 走在前、挑大梁
- 绿色低碳高质量发展先行区
- 高水平对外开放新高地
- 乡村振兴齐鲁样板
- 经略海洋、海洋强省
- 黄河流域生态保护和高质量发展
- 十大工程、十个新优势

更多时政细节见 [2026 冲刺一本通](/sprint/)。

## 建议

- 不要只看“招录人数”，先看自己是否符合所有条件。
- 不要为了上岸选完全不能接受的地区；服务期内调动很难。
- 报名前给招录机关打电话确认专业、经历等模糊条件。
