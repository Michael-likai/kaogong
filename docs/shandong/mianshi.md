# 山东省考面试形式与成绩计算

## 面试形式

山东省考面试以**结构化面试**为主，部分招录机关会组织专业能力测试。公告明确采取结构化面试等多种形式，考官和考生双抽签，面试成绩百分制。

## 进面比例

一般按职位录用计划的 **3 倍**，从达到笔试合格分数线的人员中按笔试成绩从高到低确定面试人选；部分职位可能不同，以公告和职位表为准。

## 综合成绩

未组织专业能力测试：

```text
综合成绩 = 笔试成绩 × 40% + 面试成绩 × 60%
```

组织专业能力测试：

```text
综合成绩 = 笔试 × 40% + 面试 × 40% + 专业测试 × 20%
```

面试成绩达到 60 分以上，方可确定为体检和考察人选。面试形不成竞争的职位，还需达到所在考官小组使用同一题本人员的平均分。

## 面试流程

```text
资格复审 → 签到抽签 → 候考 → 进场答题 → 退场
→ 计分 → 公布成绩 → 体检/考察
```

## 备考建议

1. **先练审题**：判断题型、身份、任务、矛盾。
2. **再搭框架**：综合分析、组织管理、人际、应急、岗位匹配各准备一套结构。
3. **开口练**：录音/录像，控制语速、口头禅、眼神和小动作。
4. **结合山东**：准备山东时政、基层治理、乡村振兴、经略海洋等本省素材。
5. **模拟考场**：找人当考官，严格限时。

::: warning 面试占比高
山东省考无专业测试时面试占 60%，笔试分差容易被逆袭。进面后要把面试当成主战场。
:::
