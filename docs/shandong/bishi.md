# 山东省考笔试内容与试卷特点

## 科目与时间

- 上午 9:00—11:00：行政职业能力测验
- 下午 14:00—17:00：申论
- 公安执法勤务等职位：另有专业科目笔试

行测、申论满分均为 100 分。

## 申论 A/B 类

2026 年度山东省考：

- **A 类**：省级机关职位
- **B 类**：省属基层单位职位

2026 年 A 卷主题涉及协同发展、产业升级、高质量发展等；B 卷更偏基层治理和具体工作场景。备考时按目标职位选对应试卷。

## 行测特点

- 题型与国考接近：常识、言语、数量、判断、资料分析。
- 山东省考常识/政治理论部分会涉及总书记对山东的讲话、山东年度部署。
- 资料分析、判断推理仍是提分重点。
- 具体题量以当年试卷为准，平时按 120 分钟整套训练。

## 成绩计算

无专业科目：

```text
笔试成绩 = 行测 × 50% + 申论 × 50%
综合成绩 = 笔试 × 40% + 面试 × 60%
```

有专业科目：

```text
笔试成绩 = 行测 × 40% + 申论 × 30% + 专业科目 × 30%
综合成绩 = 笔试 × 40% + 面试 × 40% + 专业测试 × 20%
```

## 备考重点

1. 行测先保住资料、判断、言语的正确率，数量按基础取舍。
2. 申论重点练山东真题，注意 A/B 卷差异。
3. 政治理论/省情结合山东政府工作报告、林武公开活动等时政速记。
4. 考前至少完整模考 3—5 套山东卷。

::: tip 山东特色
山东省考面试权重高（无专业测试时面试占 60%），笔试过线后不要松懈，面试要提前准备。
:::
