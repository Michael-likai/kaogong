# 山东省考报考条件与报名流程

> 以下以 2026 年度山东省考官方公告为参考，2027 年以最新公告为准。

## 基本条件

- 具有中华人民共和国国籍
- 年龄一般为 18 周岁以上、38 周岁以下；应届硕士、博士研究生可放宽到 43 周岁以下
- 具有大学专科以上文化程度
- 具备职位要求的专业、学历、学位、基层工作经历等条件
- 符合回避规定和法律法规要求的其他条件

山东省高级技工学校（技师学院）全日制毕业生，取得高级工、技师职业资格的，可分别按大专、本科学历报考符合条件且不限专业的职位。

## 基层工作经历

包括在县（市、区、旗）、乡（镇、街道）党政机关，村（社区）党组织或村（居）委会，以及各类企业、事业单位工作的经历。军队团及相当团以下单位工作、退役士兵服现役经历等也可视为基层经历。

在校期间的社会实践、实习一般不算基层工作经历；具体口径以公告为准。

## 报名流程

```text
查公告/职位表 → 网上提交报名 → 资格初审 → 缴费确认
→ 打印报名登记表/准考证 → 笔试 → 成绩 → 面试资格复审
```

2026 年度关键规则：

- 每人只能在全省范围选报 1 个职位。
- 报名与考试使用的身份证必须一致。
- 通过资格初审后不能再改报其他职位。
- 考务费每人每科 50 元；困难群体可按规定减免。
- 缴费人数达不到开考比例的职位，可能核减或取消，可按规定改报。

## 材料准备

- 身份证、学历学位证书（应届生按公告要求）
- 报名登记表、诚信承诺书
- 基层工作经历证明、社保记录（如职位要求）
- 同意报考证明（在职人员按公告要求）
- 职位要求的资格证书、党员证明等

::: warning 不要拖到最后一天
报名时间通常只有 4 天左右，资格初审和改报都需要时间。提前把职位表筛好，公告一开就报名。
:::
