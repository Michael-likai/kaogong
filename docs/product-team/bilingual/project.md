## 需求与设计
用户故事：读者能从任意页面切换中英界面，并理解备考正文尚未翻译。
验收条件：
1. 桌面与手机提供可访问、键盘可操作的中文 / English 切换入口。
2. 首页、关于页可双向切换至对应页面；文章切换不误跳首页、不产生失效链接。
3. 英文首页及关于页完整英文；导航、侧栏、页脚、搜索、主题、阅读元信息和复制按钮等界面匹配所选语言。
4. 英文界面浏览备考正文时保留中文，并出现清晰英文提示；不声称正文已翻译。
5. 刷新和直接访问所选语言地址保持语言；不强制按浏览器语言跳转。
6. 原中文 URL、文章、搜索和 Markdown 复制不回归；保留 cleanUrls/base 兼容设计。
7. 构建成功；新增页面 metadata 与语言一致，预览仍 noindex；内部项目记录不进入页面、搜索、站点地图和正文导出。
8. 桌面和手机无明显溢出；异常页面及剪贴板失败有可理解提示。
交互：复用现有主题；语言入口命名语言本身，不使用国旗；页面存在对应内容时保持路径及可用锚点。
