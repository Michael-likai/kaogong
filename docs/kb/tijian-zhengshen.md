# 体检与考察（政审）

面试通过后，进入体检和考察环节。不同岗位、不同系统的标准可能不同，**以招录机关公告和官方标准为准**。

## 体检

- 一般职位按《公务员录用体检通用标准（试行）》及操作手册执行。
- 公安、监狱、戒毒等人民警察职位，可能执行《公务员录用体检特殊标准（试行）》，并有体能测评。
- 体检在指定医疗机构进行，具体时间、地点由招录机关通知。

### 常见注意事项

- 体检前保持正常作息，避免熬夜、饮酒和剧烈运动。
- 按通知要求空腹、带齐证件。
- 有既往病史或正在服药的，提前咨询医生并如实说明。
- 对体检结果有疑问，按公告规定申请复检。

::: warning 不要自行“对号入座”
体检标准涉及具体指标和岗位差异，网上的“体检攻略”只能参考。有疑问直接咨询招录机关或指定医院。
:::

## 考察（政审）

考察内容通常包括：

- 政治素质、道德品质
- 能力素质、心理素质
- 学习和工作表现
- 遵纪守法、廉洁自律
- 是否需要回避
- 与招考职位的匹配度

考察方式可能包括实地走访、个别谈话、审核人事档案（学籍档案）、查询社会信用记录、与本人面谈等。

## 材料准备

- 身份证、准考证、报名推荐表、报名登记表
- 学历学位证书、学信网认证材料
- 档案存放证明/调档函（按通知）
- 工作经历证明、社保记录（如涉及基层经历）
- 无犯罪记录证明等（按招录机关要求）

具体清单以招录机关通知为准，提前整理，避免临时补材料。

## 公示与备案

体检、考察结束后，拟录用人员会公示 5 个工作日。公示无异议后办理备案和录用手续。
