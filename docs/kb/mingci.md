# 考公术语表

| 术语 | 含义 |
| --- | --- |
| 国考 | 中央机关及其直属机构考试录用公务员 |
| 省考 | 各省组织的公务员考试 |
| 联考 | 多个省份同一时间组织笔试 |
| 选调生 | 组织部门定向选调到基层培养的应届毕业生 |
| 参公 | 参照公务员法管理的事业单位 |
| 职位表 | 招考简章中的岗位、人数、资格条件列表 |
| 进面 | 进入面试环节 |
| 进面分 | 该岗位进入面试的最低笔试分数 |
| 调剂 | 笔试合格但未进面试，可申请其他空缺职位 |
| 递补 | 拟录用人员放弃或不合格时，按成绩依次补录 |
| 最低服务年限 | 录用后必须在岗位/地区服务的最低年限 |
| 基层工作经历 | 在县乡机关、村社区、企事业单位等工作的经历 |
| 三不限 | 不限专业、不限经历、不限政治面貌的岗位 |
| 行测 | 行政职业能力测验 |
| 申论 | 主观性试题，考查阅读、分析和写作能力 |
| 结构化面试 | 同一岗位同一套题、统一评分标准的面试 |
| 无领导小组 | 小组讨论式面试 |
| 政审 | 录用考察，了解政治素质、品行和经历 |
| 公示 | 拟录用人员名单向社会公示 |
| 备案 | 公示无异议后办理录用备案手续 |
