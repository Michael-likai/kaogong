# 常见问题

## 报名与资格

**Q：国考和省考可以同时报吗？**  
只要时间不冲突、符合条件，可以分别报名。但最终只能选择一个录用。

**Q：应届生身份怎么算？**  
一般指当年毕业、尚未落实工作单位的高校毕业生。择业期、社保、档案等口径各省不同，以公告为准。

**Q：实习算基层工作经历吗？**  
在校期间的社会实践、实习通常不算。具体以公告和报考指南为准。

**Q：专业不在职位表里怎么办？**  
先看专业大类是否匹配；不确定时直接咨询招录机关。不要凭感觉报。

**Q：在职公务员能考吗？**  
公告通常规定在职公务员和参公人员不能报考，除非满足最低服务年限并符合当地政策。以公告为准。

## 备考

**Q：行测先学哪个模块？**  
优先资料分析、判断推理，再言语、常识，数量关系按基础取舍。

**Q：申论需要背模板吗？**  
需要学结构，但不要背万能模板。先练找点、分类和成文。

**Q：每天学多久？**  
在职 2—3 小时、全职 6—8 小时是常见范围，关键在持续和复盘，不在时长。

**Q：只刷题不看课可以吗？**  
有基础可以；零基础建议先学方法，再刷题，否则容易重复犯错。

## 面试与后续

**Q：面试要不要报班？**  
看个人表达基础和自律程度。报班主要解决开口练和模拟考场，不是必需。

**Q：面试比例是多少？**  
常见 3:1，部分岗位不同；以招考简章和面试公告为准。

**Q：体检不合格还有机会吗？**  
按公告规定申请复检；特殊岗位标准更严。具体咨询招录机关。

**Q：公示后放弃会有什么影响？**  
可能记入诚信档案，影响后续报考。放弃前务必看清公告和当地政策。

::: tip 不确定就问
涉及资格、专业、经历、服务期的问题，最可靠的方式是直接联系招录机关，而不是在社交平台问网友。
:::
