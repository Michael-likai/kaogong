# 真题与官方资料

## 官方资料优先级

1. **考试公告**：报考条件、流程、时间。
2. **考试大纲**：行测、申论考什么、怎么考。
3. **职位表/招考简章**：岗位限制、招录人数、专业要求。
4. **报考指南**：政策口径和常见问题。
5. **面试公告**：面试形式、时间、材料要求。

国考专题网站：<http://bm.scs.gov.cn/kl2027>  
国家公务员局：<https://www.scs.gov.cn/>

省考、事业单位等以各省组织部门、人社厅、人事考试网公告为准。

## 真题怎么用

| 阶段 | 用法 |
| --- | --- |
| 基础期 | 按模块做近 3—5 年真题，熟悉题型 |
| 强化期 | 限时套卷，练答题顺序和时间分配 |
| 冲刺期 | 按考试时间全真模考，复盘错题 |

建议优先做**目标考试**的真题：国考做国考卷，省考做目标省份的卷子，不要只刷模拟题。

## 刷题原则

1. **先质量后数量**：一套卷吃透，比十套卷对答案有用。
2. **限时**：平时不限时，考场一定做不完。
3. **复盘**：错题、蒙对的题、超时的题都要看。
4. **留最新卷**：最近 1—2 年真题留到冲刺阶段模考。

## 关于模拟题

模拟题可以用来练速度、练新题型，但不要用它代替真题。部分模拟题难度和命题风格与真题差距较大。

::: warning 注意资料时效
考试政策、题型和分值可能变化。用旧资料时，先核对当年考试大纲和公告。
:::
