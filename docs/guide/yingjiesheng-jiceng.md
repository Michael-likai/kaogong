# 应届生、基层工作经历与年龄

## 应届生身份

一般来说，当年毕业、尚未落实工作单位的高校毕业生属于应届生。不同考试、不同省份对“择业期”“未缴纳社保”“档案保留”等认定口径不同，**以当年公告和报考指南为准**。

应届生优势：

- 国考市（地）级及以下直属机构主要招录应届高校毕业生。
- 部分岗位仅限应届生，竞争范围更小。
- 选调生通常要求应届生身份。

## 基层工作经历

公告中的基层工作经历，通常包括：

- 在县（市、区、旗）、乡（镇、街道）党政机关工作
- 在村（社区）党组织或村（居）委会工作
- 在各类企业、事业单位工作
- 军队团及相当团以下单位工作、退役士兵服现役经历
- 离校未就业高校毕业生到实习见习基地参加见习，或到企事业单位参与项目研究

注意：**在校期间的社会实践、实习，一般不算基层工作经历**；具体以公告为准。

## 年龄

2027 国考公告规定：

- 一般为 18 周岁以上、38 周岁以下
- 2027 年应届硕士、博士研究生，放宽到 43 周岁以下

年龄计算以公告规定的出生日期区间为准，报名前用自己的身份证日期核对一遍。

## 常见误区

1. “签了三方就算落实工作”——不一定，看公告和社保、档案口径。
2. “实习也算基层经历”——多数情况下不算。
3. “只要专业沾边就能报”——以职位表专业要求为准，必要时直接咨询招录机关。
