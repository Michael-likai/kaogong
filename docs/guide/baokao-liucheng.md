# 报考流程与时间节点

## 一张图理解流程

```text
注册认证 → 查职位表 → 提交报名 → 等资格审查 → 查询报名序号
→ 报名确认 + 缴费 → 打印准考证 → 笔试 → 成绩/面试
```

## 1. 注册与实名认证

先在专题网站注册，按提示完成实名实人认证。**注册认证和报名是两个时间窗口**，认证截止通常早于报名截止；不要拖到最后一天。

## 2. 筛选职位

下载《招考简章》职位表，按以下顺序筛：

1. 专业、学历、学位
2. 政治面貌、基层工作经历、服务年限
3. 工作地点、是否服从调剂
4. 招录人数与历年竞争情况（仅作参考）

每次只能报考 1 个职位。通过资格审查后不能再改报其他职位；在报名截止前，未审查或未通过审查的可以改报。

## 3. 提交报名与等待审查

- 报名信息要真实、准确、完整。
- 提交后定期登录查看审查结果。
- 审查通过后，记住报名序号。

## 4. 报名确认与缴费

通过资格审查后，在规定时间内完成报名确认并缴费。逾期未完成视为自动放弃。最低生活保障家庭人员可按当地考试机构要求办理减免。

## 5. 打印准考证

按公告时间登录专题网站打印，建议多打印几份并保存电子版。准考证上有考点、考场和考试时间。

## 6. 参加笔试

- 提前熟悉考点路线，异地考试提前订酒店。
- 带齐准考证、有效身份证件和考试文具。
- 开考 15 分钟后禁止入场，不要卡点。

## 7. 成绩、调剂与面试

笔试成绩一般在次年 1 月公布。达到合格分数线但未进面试的考生，可以关注调剂公告；进入面试后按招录机关要求准备材料、参加面试、体检和考察。

::: tip 报名期最重要的一件事
把“职位表筛选”和“报名材料”提前准备好，报名窗口一开就提交，给资格审查和改报留出时间。
:::
