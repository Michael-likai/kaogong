# 选岗思路

选岗不是“选最好的”，而是**选你符合条件、愿意去、考得上的**。

## 先做排除法

1. **专业**：以职位表专业要求为准，注意专业大类与小类的区别。
2. **学历/学位**：是否要求“仅限本科”“硕士研究生及以上”“双证齐全”。
3. **政治面貌**：党员、团员、不限。
4. **基层工作经历**：中央和省级机关多要求 2 年以上。
5. **服务年限/特殊体检**：艰苦边远地区、公安、监狱等有额外要求。
6. **工作地点**：是否接受异地、乡镇、驻外或经常出差。

## 再看竞争度

| 维度 | 观察方法 |
| --- | --- |
| 招录人数 | 招 1 人和招 5 人，容错率完全不同 |
| 限制条件 | 限制越多，符合人数通常越少，但不绝对 |
| 历年进面分 | 只作参考，不要直接套用 |
| 报名人数 | 报名期间会更新，最后两天变化最大 |

::: warning 避开“三不限”盲目冲
不限专业、不限经历、不限政治面貌的岗位，报名人数往往最多。除非分数很有把握，否则优先考虑“限制匹配度高”的岗位。
:::

## 三个现实问题

- **能不能去**：异地、基层、服务期，能不能接受？
- **适不适合**：体检、体能、政治考察有没有硬伤？
- **值不值**：为了上岸去一个完全不想待的地方，未必划算。

## 建议记录表

把候选岗位做成表格：单位、职位、招录人数、专业要求、基层经历、地点、历年分数、报名人数、个人匹配度。报名前再横向比较一次。
