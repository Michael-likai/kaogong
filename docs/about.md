# 关于考公小助手

考公小助手是一个面向公务员考试备考的资料站，把报考流程、行测、申论、面试和资料整理在一起，方便检索和长期更新。

## 内容范围

- **报考指南**：2027 国考公告、报名流程、选岗、应届生与基层经历、备考规划
- **行测**：五大模块的题型、方法和刷题策略
- **申论与面试**：申论题型与结构、素材积累、面试形式与答题框架
- **资料库**：官方资料入口、体检政审、常见问题、术语表

## 内容来源

- 国家公务员局 2027 年度考试录用公务员公告
- 中央机关及其直属机构考试录用公务员专题网站
- 公开的考试大纲、官方媒体和各地组织部门公告
- 通用备考方法与经验整理

## 免责声明

本站为个人整理的学习资料，**非官方站点**。考试政策、职位条件、时间安排和分数线可能调整，请以国家公务员局、各省组织部门及招录机关发布的最新公告为准。

如果发现内容错误或过期，欢迎反馈，我们会尽快核对和修订。

## 更新方式

内容以 Markdown 维护，持续补充和修订。后续会继续整理真题使用方法、面试题型和各省考情。
