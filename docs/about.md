# 关于考公小助手

考公小助手是一个面向公务员考试备考的资料站，把报考流程、行测、申论、面试和资料整理在一起，方便检索和长期更新。

## 内容范围

- 报考指南：公告、选岗、报名与流程
- 行测：分模块的题型、方法和错题记录
- 申论与面试：写作结构、素材和表达训练
- 资料库：真题、笔记、经验和常见问题

## 更新方式

内容以 Markdown 维护，后续会持续补充和修订。如果你发现错误或有想补充的内容，欢迎反馈。
