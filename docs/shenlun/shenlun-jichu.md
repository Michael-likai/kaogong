# 申论基础

## 试卷分类

国考公共科目笔试试卷分 3 类：

1. 中央机关及其省级直属机构综合管理类
2. 市（地）级及以下直属机构综合管理类
3. 行政执法类

不同类别的材料主题、题型和作答要求会有差异，练真题时要对应自己的岗位类别。

## 常见题型

| 题型 | 问法 | 核心 |
| --- | --- | --- |
| 归纳概括 | 概括问题/经验/原因 | 找点全、分类清 |
| 综合分析 | 谈谈对某句话/现象的理解 | 解释 + 分析 + 结论 |
| 提出对策 | 提出解决建议 | 针对问题、可执行 |
| 贯彻执行 | 写讲话稿/倡议书/汇报等 | 格式 + 内容 + 身份 |
| 文章写作 | 根据材料写议论文 | 立意准、结构稳、论证实 |

## 答题基本结构

1. **审题**：看清作答对象、范围、字数、身份、文体。
2. **找点**：回材料定位关键词、问题、原因、对策、案例。
3. **分类**：按主体、层面、时间或逻辑分组。
4. **成文**：总起句 + 分条展开 + 收束。

## 评分逻辑

- **踩点给分**：关键词、要点是否齐全。
- **逻辑清晰**：分层合理，不重复不交叉。
- **语言规范**：简洁、准确、符合机关文风。
- **字数与格式**：严格遵守要求，格式错误会扣分。

## 常见失分点

- 不看身份和文体，写成“万能模板”。
- 要点堆砌，不分类。
- 对策空泛，没有针对材料中的问题。
- 大作文立意偏题，或通篇喊口号。

::: warning 申论不是“抄材料”
要点来自材料，但要用自己的语言归纳、分类、组织。整段照抄会显得没有加工能力。
:::
