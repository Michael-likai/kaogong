# 面试入门

## 常见面试形式

| 形式 | 特点 |
| --- | --- |
| 结构化面试 | 同一岗位同一套题、同一评分标准，最常见 |
| 结构化小组 | 3—4 人一组，答题 + 点评 + 回应 |
| 无领导小组讨论 | 给定材料，小组讨论达成一致 |
| 半结构化/面谈 | 结合个人经历追问，部分单位使用 |

具体形式以招录机关面试公告为准。

## 结构化面试流程

```text
签到抽签 → 候考 → 进入考场 → 考官读题/看题 → 思考作答
→ 退场 → 计分 → 公布成绩
```

常见题量 3—5 道，时间 15—25 分钟，剩余时间会提醒。

## 评分维度

- 综合分析能力
- 计划组织协调能力
- 人际交往与沟通能力
- 应变能力
- 言语表达与举止仪表
- 岗位匹配与自我认知

## 备考方法

1. **先学审题**：判断题型、身份、任务、矛盾。
2. **再搭框架**：每种题型准备 1—2 个稳定结构。
3. **开口练**：录音/录像，控制语速、口头禅和小动作。
4. **模拟考场**：找人对练，限时思考、限时作答。
5. **积累素材**：把申论素材迁移到面试表达中。

::: tip 内容 > 套路
框架是骨架，内容才是血肉。答题时结合题目具体情境，不要背万能模板。
:::
