# 素材积累与使用

## 素材分四类

| 类型 | 例子 | 用途 |
| --- | --- | --- |
| 政策理论 | 重要会议、政策文件 | 提升立意 |
| 人物案例 | 基层干部、时代楷模 | 论证观点 |
| 社会现象 | 基层治理、公共服务 | 分析问题 |
| 数据事实 | 统计数据、调研结论 | 增强说服力 |

## 怎么积累

1. **按主题建卡片**：基层治理、乡村振兴、营商环境、民生保障、文化建设、生态保护、数字政府等。
2. **每个主题记 2—3 个案例 + 1 组数据 + 1 句政策表述**。
3. **用自己的话复述**，不要整段背。
4. **每周用一次**：写进申论小题或面试答题里，检验是否真的会用。

## 怎么用

- **开头**：用政策或现象引出主题，不要堆砌名言。
- **论证**：一个观点配一个案例或一组数据，避免“例子开会”。
- **结尾**：回扣主题，提出方向，不喊空口号。

## 素材来源建议

- 官方媒体和政府网站：人民日报、新华社、中国政府网、地方政务发布
- 政策文件和白皮书
- 正规新闻报道和调研报告

::: tip 少而精
准备 10 个高频主题、每个主题 2 个案例，比收藏 100 篇素材更有用。关键不是“看过”，而是“能用出来”。
:::
