# 申论与面试

申论和面试本质上都是“把观点讲清楚”。申论看书面表达，面试看口头表达，底层能力相通。

::: tip 先练结构，再练语言
申论先学“怎么找点、怎么分层”，面试先学“怎么审题、怎么搭框架”。模板只能救急，结构才是稳定得分的关键。
:::
