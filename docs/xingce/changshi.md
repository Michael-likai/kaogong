# 常识判断

常识判断考查政治、法律、经济、历史人文、地理、科技生活等。范围广，但不建议花大量时间死记。

## 复习范围

- **政治**：时政、重要会议、政策文件
- **法律**：宪法、民法典、行政法基础
- **经济**：宏观政策、常用经济概念
- **历史人文**：中国古代史、文学常识、传统文化
- **地理**：中国地理、自然地理基础
- **科技生活**：物理化学生物常识、生活安全

## 方法

1. **碎片时间积累**：每天 10—15 分钟看时政和常识卡片。
2. **抓高频**：法律、政治、科技是高频区。
3. **不要钻牛角尖**：偏题怪题性价比低。
4. **考场快做**：会就会，不会就选，控制在 8—10 分钟。

## 考场策略

- 先做有把握的题，不确定的标记后统一处理。
- 绝对化表述、明显违背常识的选项通常可排除。
- 不要在一道题上超过 1 分钟。

> 常识靠长期积累，考前突击只能补时政，不能补全部。
