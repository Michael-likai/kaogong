# 判断推理

判断推理题型稳定、方法性强，是行测提分重点。

## 四大题型

| 题型 | 关键 |
| --- | --- |
| 图形推理 | 找规律：数量、位置、样式、属性、立体 |
| 定义判断 | 抓定义要件，逐项比对 |
| 类比推理 | 找关系：语义、逻辑、语法、经验 |
| 逻辑判断 | 翻译推理、真假推理、加强削弱、排列组合 |

## 图形推理

先观察，再套规律：

1. 图形组成相同 → 看位置（平移、旋转、翻转）
2. 组成相似 → 看样式（叠加、遍历、加减同异）
3. 组成不同 → 看数量（点、线、面、角、素）或属性（对称、曲直、开闭）

## 定义判断

- 先圈出定义的关键要件：主体、对象、条件、方式、结果。
- 用要件逐一排除选项，不要凭感觉。
- 注意“不属于”的问法。

## 逻辑判断

- **翻译推理**：记住“如果…那么…”“只有…才…”的推理规则。
- **真假推理**：找矛盾关系、反对关系。
- **加强/削弱**：先找论点、论据，再判断选项是否切断/加强联系。
- **排列组合**：列表、代入、排除。

## 提分方法

- 图形推理每天 10—15 题，保持敏感度。
- 逻辑判断重点练“论证”题，占比高。
- 错题按“规律没看出来/要件漏了/论证方向错”分类。
