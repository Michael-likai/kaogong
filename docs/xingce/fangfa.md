# 刷题与复盘方法

## 刷题节奏

| 阶段 | 每天题量 | 重点 |
| --- | --- | --- |
| 基础 | 30—50 题 | 分模块，重在理解方法 |
| 强化 | 60—100 题 | 限时，找短板 |
| 冲刺 | 1 套整卷 | 时间分配和取舍 |

## 错题本怎么记

每道错题只记四件事：

1. 题型
2. 错因（不会/看错/算错/超时）
3. 正确方法的关键一步
4. 同类题特征

每周回看一次，把“反复错”的题型单独加练。

## 模考

- 严格按考试时间：上午行测、下午申论。
- 用答题卡涂卡，模拟真实节奏。
- 模考后先自己复盘，再看解析。
- 记录每个模块用时和正确率，调整答题顺序。

## 时间分配参考

```text
常识 8—10 分钟
资料分析 25—30 分钟
判断推理 30—35 分钟
言语理解 30—35 分钟
数量关系 10—15 分钟
涂卡检查 5 分钟
```

## 三个原则

- **先准确，后速度**：正确率不稳定时不要盲目提速。
- **先强项，后弱项**：考场上先拿能拿的分。
- **定期模考**：不做整卷，永远不知道自己的时间分配问题。
