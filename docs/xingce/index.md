# 行测

行政职业能力测验（行测）是客观题，核心不是“会不会”，而是**在有限时间内拿到最多分**。

## 五大模块

| 模块 | 特点 | 提分优先级 |
| --- | --- | --- |
| 资料分析 | 方法固定、分值高、可训练 | 高 |
| 判断推理 | 题型稳定、技巧性强 | 高 |
| 言语理解 | 题量大、靠积累和语感 | 中高 |
| 常识判断 | 范围广、单题快 | 中 |
| 数量关系 | 难度分化大、耗时 | 视基础而定 |

## 答题顺序建议

常见顺序：**常识 → 资料分析 → 判断 → 言语 → 数量**。也可以把最擅长的模块放前面，原则是：

1. 先做能稳定得分的模块；
2. 数量关系不要死磕，留 10—15 分钟挑会做的；
3. 最后留 5 分钟涂卡和检查。

国考行测通常 130—135 题、120 分钟，具体以当年试卷为准。平均每题不到 1 分钟，**放弃是策略的一部分**。
