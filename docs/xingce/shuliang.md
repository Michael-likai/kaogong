# 数量关系

数量关系是行测里最容易“耗时还不一定对”的模块。策略比刷题量更重要。

## 常见题型

- 工程问题
- 行程问题
- 经济利润
- 排列组合与概率
- 几何问题
- 容斥、年龄、钟表、浓度等

## 取舍策略

1. **先挑会做的**：每题扫一眼，30 秒内没有思路就跳过。
2. **目标不是全做**：10—15 分钟做 5—8 道，剩下统一蒙。
3. **优先做套路题**：工程、行程、利润、容斥等方法固定。
4. **最后涂卡**：不要因为一道题影响整体节奏。

## 常用方法

- **方程法**：最通用，先设未知数找等量关系。
- **赋值法**：工程、行程、利润题常用。
- **比例法**：抓住不变量。
- **代入排除**：选项代入，适合年龄、余数、不定方程。
- **数字特性**：奇偶、倍数、尾数，快速排除。

## 练习建议

- 按题型专项练，每个题型先掌握 2—3 种固定解法。
- 限时训练：10 题 12 分钟，逐步压缩。
- 错题记录“卡在哪一步”，而不是只记答案。

::: warning 不要死磕
数量关系不是拿分主力。基础一般时，保证资料、判断、言语的准确率，比死磕数量更划算。
:::
