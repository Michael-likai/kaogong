# 言语理解

言语理解题量大，是行测的基本盘。核心能力是**快速抓主旨、辨逻辑、看语境**。

## 主要题型

| 题型 | 关键 |
| --- | --- |
| 逻辑填空 | 语境 + 词语辨析，先找呼应点 |
| 片段阅读 | 找主旨句、转折/因果/对策 |
| 语句表达 | 排序、衔接、下文推断 |
| 篇章阅读（部分考试） | 快速定位 + 整体理解 |

## 逻辑填空

1. 先读题干，找**呼应点**（解释、并列、转折、递进）。
2. 再看词语的搭配、程度、感情色彩。
3. 不要只凭语感，要能说出“为什么选它”。

## 片段阅读

- **主旨题**：找总起句、总结句、对策句。
- **意图题**：作者想说明什么，常落在对策或呼吁。
- **细节题**：回原文逐项比对，警惕偷换概念。
- **标题题**：覆盖全文，不要只抓局部。

## 提分方法

- 每天 20—30 题，限时完成。
- 错题按“题型 + 错因”分类：没找到主旨、词语辨析错、被干扰项带偏。
- 积累高频成语和易混词，但不要背词典。

::: tip 言语不要过度推理
答案通常在文段里，不要用自己的背景知识替代原文。抓住“作者说了什么”，而不是“我觉得应该是什么”。
:::
