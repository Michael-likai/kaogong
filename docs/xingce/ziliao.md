# 资料分析

资料分析是行测性价比最高的模块：方法固定、分值高、通过训练可以稳定提分。

## 核心公式

- 增长率 =（现期 − 基期）÷ 基期
- 增长量 = 现期 − 基期 = 基期 × 增长率
- 比重 = 部分 ÷ 整体
- 平均数 = 总量 ÷ 份数
- 倍数 = A ÷ B
- 年均增长率：注意“年均”与“同比”的区别

## 速算方法

1. **截位直除**：根据选项精度保留 2—3 位。
2. **分数比较**：交叉相乘、化同分子/分母。
3. **特征数字**：把百分数转成熟悉分数。
4. **估算 + 排除**：选项差距大时不要精算。

## 常见陷阱

- 时间陷阱：同比/环比、累计/当期、年初/年末。
- 单位陷阱：万、亿、百分点、百分号。
- 概念陷阱：增长量 vs 增长率、比重 vs 倍数。
- 范围陷阱：全国/某省/某行业。

## 训练方法

- 每天 1—2 篇材料，限时 15—20 分钟。
- 先看问题，再回材料定位数据。
- 错题记录“公式错/找数错/计算错/掉陷阱”。
- 目标：正确率 80% 以上，单篇 6—8 分钟。

::: tip 先保准确，再提速度
资料分析最怕“算得快但算错”。先把公式和找数练稳，再逐步压缩时间。
:::
